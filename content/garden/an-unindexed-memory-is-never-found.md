An assistant's memory that no index line names is not found by its description.

## The test

A memory was written with a maximally distinctive description and planted unindexed, meaning no line in the index pointed at it. A fresh session was then started with its tools forbidden.

The session did not surface the memory. On two turns the result was "UNKNOWN", no recalled-memory block, and the memory not in the index.

## What the documentation describes

The documentation describes the index being read at the start of a session, and after that the assistant reading files with tools. It defines only one metadata field for a memory file. It describes no mechanism that recalls a memory by its own metadata.

## The rule that follows

"There is no frontmatter recall." An index line or a name in the instructions file is the only route to a memory. A description, however distinctive, does not create one.

The index header had claimed otherwise. That claim was corrected.

## Limits of the claim

The test used one planted memory and one fresh session, run over two turns.
